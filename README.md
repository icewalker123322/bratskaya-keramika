# Братская керамика

Статический сайт керамической мастерской с панелью управления на Supabase.

## Локальный запуск

```sh
python -m http.server 8093 --bind 127.0.0.1
```

Сайт: http://127.0.0.1:8093/ — админка: http://127.0.0.1:8093/admin/.

Сборка и установка npm-пакетов не требуются. Для динамического контента и входа нужен доступ к Supabase и CDN esm.sh. В браузере используется только публичный publishable key; права на изменения проверяются RLS. Пароль владельца не хранится в репозитории.

## GitHub Pages

После загрузки файлов откройте Settings → Pages в репозитории. В Build and deployment выберите Deploy from a branch, ветку `main` и каталог `/ (root)`. Сохраните настройки и дождитесь успешного развёртывания Pages. Файл `.nojekyll` позволяет публиковать статические файлы напрямую.

Панель доступна по адресу опубликованного сайта с добавлением `admin/`. Все внутренние пути относительные и поддерживают размещение в подкаталоге репозитория.

## Управление и проверки

- [Настройка Supabase и инструкция владельца](ADMIN_SETUP.md).
- [Результаты проверок и ограничения](VERIFICATION.md).
- `supabase/schema.sql` и `supabase/seed.sql` — первоначальная установка базы. В текущем проекте она уже выполнена; не запускайте schema.sql повторно.
- `qa-auth.mjs` — проверка реального входа и RLS, пароль получает только через скрытый stdin.
- `qa-browser.mjs` — первоначальные браузерные проверки до подключения Supabase. Его проверка отсутствующей конфигурации требует отдельного тестового окружения без подключённого проекта.

Настройка и проверка загрузки фотографий в Storage ещё не завершены. Исходные фотографии сайта находятся в `assets/`.
