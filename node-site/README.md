# Текущий сайт и админ-панель «Братская керамика»

Версия из локального проекта на 12 ноября 2026 года. Сайт и админка работают на одном Node.js-сервере. Существующая статическая версия в корне репозитория сохранена отдельно.

## Запуск

Нужен Node.js 22 или новее; дополнительных npm-зависимостей нет.

```sh
cd node-site
npm start
```

Сайт: http://127.0.0.1:4173/

Админка: http://127.0.0.1:4173/admin

При первом запуске автоматически создаётся случайный пароль в `data/admin-password.txt`. Этот файл не входит в Git. На сервере можно задать секрет `ADMIN_PASSWORD` через окружение. Не записывайте пароль в исходники или публичный репозиторий.

`data/default.json` содержит начальное публичное содержимое, цены и расписание. Рабочие изменения сохраняются в `data/content.json`. Исходные фото для первого запуска включены в `public/seed-uploads` и автоматически копируются в рабочее хранилище при запуске. Пароли, заявки, резервные копии и локальные журналы в репозиторий не включены.

## Хостинг с работающей админкой

GitHub хранит исходники. GitHub Pages не выполняет `server.mjs` и не поддерживает сохранение через эту Node.js-админку. Для данной версии нужен Node.js-хостинг или Docker, с постоянным диском для данных и загрузок.

```sh
docker build -t bratsk-ceramics .
docker run -d --name bratsk-ceramics -p 8080:8080 -v bratsk-ceramics-data:/storage bratsk-ceramics
```

Контейнер обслуживает сайт на `/`, админку на `/admin`. Пароль генерируется в `/storage/data/admin-password.txt`; задавайте `ADMIN_PASSWORD` через секреты хостинга, если требуется собственный. Перед контейнером предусмотрите HTTPS-прокси. Для HTTP-проверки на своём ПК используйте `-e COOKIE_SECURE=0`; в интернете оставьте Secure-cookie включённым.

Переменные окружения:

| Переменная | Значение |
| --- | --- |
| `HOST` | `127.0.0.1` по умолчанию; `0.0.0.0` для контейнера/сервера |
| `PORT` | `4173` по умолчанию |
| `DATA_DIR` | Постоянный каталог для рабочего контента и заявок |
| `UPLOADS_DIR` | Постоянный каталог загруженных фото |
| `ADMIN_PASSWORD` | Секрет входа; не публиковать |
| `COOKIE_SECURE` | `1` за HTTPS-прокси |
